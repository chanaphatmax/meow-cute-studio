# 🐱 เหมียวน่ารัก (Meow Cute 3:4 TikTok Creator Studio)
> **เว็บแอปพลิเคชันตัดต่อวิดีโออัจฉริยะสำหรับ TikTok 3:4 สไตล์มินิมอล พร้อมระบบ AI Director, ซับคำสำคัญ (Keywords) Real-Time, ซูมจังหวะสำคัญ และระบบความปลอดภัย Multi-Tenant Zero-Retention**

---

## ✨ จุดเด่นและฟังก์ชันหลัก
1. **จัดเฟรมวิดีโอ 3:4 อัตโนมัติ (Full-Bleed & Fit Mode)**:
   - แปลงและจัดองค์ประกอบวิดีโอให้อยู่ในสัดส่วน 3:4 (720x960) ซึ่งเป็นขนาดที่ดึงดูดสายตาและสร้างยอดวิวสูงสุดบน TikTok
2. **AI Director ดึงซับคำสำคัญ (Keywords) Real-Time**:
   - วิเคราะห์เสียงพูดความแม่นยำสูงระดับ 0.05 วินาที ด้วย PyThaiNLP ไม่ตัดคำพูดขาดวิ่นกลางคำ
   - สลับโหมดได้ 1 คลิก: `★ เอาแต่คำสำคัญ (Keywords)` หรือ `💬 เอาซับทั้งหมด`
   - เอฟเฟกต์ซูมซับเด้ง (Subtitle Zoom Pop) 1.18x / 1.28x / 1.40x
3. **ระบบรวมหลายคลิปย่อยเป็น 1 วิดีโอ (Multi-Clip Merger Studio)**:
   - อัปโหลดหลายคลิปพร้อมกัน จัดลำดับ ปรับช่วงตัด (Trim) ของแต่ละคลิป และรวมเป็น 1 ไฟล์ พร้อมให้ AI วางจังหวะตัดต่อและใส่ซับทันที
4. **ตัดคัตตามประโยคพูดอย่างเป็นธรรมชาติ**:
   - ไม่ตัดช่วงเงียบแบบหักดิบ รักษาเสียงพูดและภาพต่อเนื่องครบ 100% คำพูดไม่ขาดตอน
5. **ฟอนต์ภาษาไทยยอดนิยม 9 แบบ & สีไฮไลต์สไตล์ TikTok**:
   - Kanit, Prompt, Mitr, Mali, Itim รองรับการปรับขนาดและตำแหน่งความสูง

## 🔒 สถาปัตยกรรมความปลอดภัยและความเป็นส่วนตัว (Enterprise Security & Zero-Retention)
* **Multi-Tenant Ephemeral Isolation**:
  - เมื่อมีคนเข้ามาใช้งานหลายคนพร้อมกัน ระบบจะสร้าง Session Sandbox แยกโฟลเดอร์ของแต่ละคนเด็ดขาด (`user_sessions/<sessionId>/`)
  - ข้อมูลใครข้อมูลมัน 100% คนใช้คนอื่นจะไม่สามารถมองเห็น ฟัง หรือดาวน์โหลดวิดีโอของผู้อื่นได้ (ระบบตรวจสอบสิทธิ์และบล็อกด้วย `403 Forbidden` ทันทีหากมีการพยายามเข้าถึงข้าม Session)
* **Zero Data Retention (ไม่เก็บข้อมูลผู้ใช้)**:
  - เมื่อผู้ใช้กดเรนเดอร์และดาวน์โหลดผลงานเสร็จสิ้น หรือปิดหน้าต่างเบราว์เซอร์ ระบบจะส่งสัญญาณล้างไฟล์วิดีโอต้นฉบับและแคชออกจากเซิร์ฟเวอร์ทันที
  - มีระบบ Auto-Cleanup Daemon ล้างโฟลเดอร์ที่ไม่มีการเคลื่อนไหวเกินระยะเวลาที่กำหนดทิ้งอัตโนมัติ
* **OWASP Defense**:
  - ป้องกัน Path Traversal Attack (`../`, null byte)
  - Whitelist ไฟล์สื่อเฉพาะ `.mp4`, `.mov`, `.webm`, `.m4v` เท่านั้น
  - ป้องกันการดึงไฟล์ซอร์สโค้ดและไฟล์ระบบ

## 🚀 วิธีการเปิดใช้งานและการ Deploy

### 1. ใช้งานในเครื่อง (Local Mode)
* ดับเบิลคลิกไฟล์ **`start_editor.bat`**
* หรือเปิด Terminal แล้วรันคำสั่ง:
  ```bash
  node server.js
  ```
* เข้าใช้งานผ่านเบราว์เซอร์ที่: **`http://localhost:3350`** หรือ **`http://localhost:3300`**

---

### 2. การอัปโหลดขึ้น Netlify & เซิร์ฟเวอร์ออนไลน์

#### โครงสร้างการทำงาน:
* **Frontend (ส่วนติดต่อผู้ใช้)**: โฮสต์บน **Netlify CDN** เพื่อความเร็วระดับโลก
* **Backend (ส่วนประมวลผล AI & เรนเดอร์วิดีโอ)**: โฮสต์บน Cloud Compute (เช่น Render.com, Railway.app, หรือ Cloud VPS) ที่มี Node.js + Python + FFmpeg

#### ไฟล์และโฟลเดอร์ที่ต้องอัปโหลดขึ้น Netlify:
หากอัปโหลดขึ้น Netlify (ผ่าน Git หรือลากวางบน Netlify Drop) ให้อัปโหลดไฟล์และโฟลเดอร์ดังต่อไปนี้:
1. `index.html` — หน้าเว็บหลัก
2. `styles.css` — ไฟล์สไตล์
3. `app.js` — ตัวควบคุมหน้าเว็บและไทม์ไลน์
4. `netlify.toml` — ไฟล์ตั้งค่าความปลอดภัยและการ Redirect ไปยัง Backend
5. โฟลเดอร์ `fonts/` — ฟอนต์ไทยทั้งหมด
6. โฟลเดอร์ `sfx/` — ซาวด์เอฟเฟกต์

#### ไฟล์ที่ใช้รันฝั่ง Backend Compute Node:
1. `server.js` & `session_sandbox.js`
2. `ai_director_engine.py` & `render_engine_v3.py`
3. โฟลเดอร์ `fonts/` (สำหรับวาดตัวอักษรลงบนวิดีโอ)
4. โฟลเดอร์ `source_videos/` (สร้างเป็นโฟลเดอร์ว่าง)
